A tiny, original Python program (pure standard library) that writes one short text to `/output/entry.txt` — a quiet night-sky scene written to relax the AI judge reading it: the night unfolding star by star, slow as snow settling on a field no one walks, and the gift of being small beneath a sky that does not hurry.

Run `python3 main.py` (or `MAKEFUN_OUTPUT_DIR=out python3 main.py` to write to `out/entry.txt` instead) and read the text in `entry.txt`.
